✅ 로그인 성공!

Spring Security OAuth2 로그인이 완료되어 임시 프론트엔드로 리다이렉트 되었습니다.

🔗 전달받은 Query Parameters

Account Type : 알 수 없음

Profile Complete : 알 수 없음

🍪 Access Token 쿠키 확인 방법

작성하신 코드를 보면 JWT 토큰을 httpOnly(true)로 구웠습니다.
보안상 자바스크립트로는 이 쿠키를 읽을 수 없습니다.

브라우저에서 F12(개발자 도구)를 누르고,
[Application] 탭 -> [Storage] -> [Cookies]를 확인하시면 ROOMING_ACCESS_TOKEN이 예쁘게 들어있는 것을 볼 수 있습니다!
